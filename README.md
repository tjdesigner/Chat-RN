# Chat-RN

Este repositório contém um sistema de chat em tempo real, composto por um backend (Node.js, Express, Socket.IO, MongoDB) e um frontend mobile (React Native).

## Objetivo

O objetivo do projeto é fornecer uma aplicação de chat moderna, com autenticação, troca de mensagens em tempo real e interface mobile, servindo como base para estudos, prototipação ou expansão para soluções de comunicação.

## Estrutura do Projeto

- `backend/` — API REST, autenticação, WebSocket e persistência de dados.
- `mobile/` — Aplicativo React Native para interação do usuário.
